# 越语听 Chrome 扩展

在 YouTube 视频页点击扩展图标，一键将当前视频链接带入越语听。扩展只读取用户主动点击时的当前标签页地址，不读取页面内容，不保存浏览记录。

## 本地安装测试

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开任意 YouTube 视频，点击浏览器工具栏中的“越语听”。

## 商店提交

上传 `dist/yueyuting-chrome-1.0.0.zip`。建议单一用途描述：

> 将当前 YouTube 视频链接一键带入越语听，生成中文字幕并使用中文语音播放。

权限说明：`activeTab` 仅在用户点击扩展时读取当前标签页地址，以识别当前 YouTube 视频；不读取页面内容，不持续跟踪浏览活动。
