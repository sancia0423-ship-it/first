# Chrome Web Store 商店文案

## 名称

越语听

## 简短说明

一键将当前 YouTube 视频带入越语听，生成中文字幕并使用中文语音播放。

## 详细说明

越语听帮助中文用户理解带公开字幕的 YouTube 长视频。

打开任意 YouTube 视频后，点击扩展图标即可自动识别当前视频链接，并跳转到越语听。你也可以在扩展中手动粘贴 YouTube 链接。

越语听网站支持：

- 逐句中文字幕与双语对照
- 点击字幕跳转到视频对应时间
- 字幕搜索与时间戳笔记
- 浏览器中文语音播放
- SRT 字幕下载
- AI 内容解释与问答

隐私说明：扩展仅在用户主动点击时读取当前标签页地址，用于识别 YouTube 视频；不读取页面正文，不保存浏览记录，不出售或共享用户数据。
